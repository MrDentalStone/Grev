# Grev

> Fork of [grov](https://github.com/TonyStef/Grov) - Collective AI memory for engineering teams.

**Status:** Under Development

## What is Grev?

Grev extends grov with role-based context injection for structured AI-assisted development workflows.

## Features (Planned)

- [ ] Role-based modes (Manager / Developer)
- [ ] Enhanced context injection
- [ ] Workflow-specific prompts
- [ ] Integration with project state management

## Installation

```bash
npm install -g grev
```

## Usage

```bash
grev proxy --role manager    # Manager mode
grev proxy --role developer  # Developer mode
grev proxy                   # Default (no role injection)
```
